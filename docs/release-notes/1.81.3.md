## JARVIS 1.81.3: Cold glass pressure release

## What's new

- Opening any suit case releases a brief wisp of cold mist from its lower seals.
- The mist drifts outward and clears in about 1.2 seconds, staying below the suit's upper body.
- Low graphics and battery mode use two light wisps; medium uses four and high/ultra use six. Reduced motion and animations-off disable the mist.
- The effect uses the existing opening sequence and renderer, without extra videos or sound. All earlier hall, suit, Batmobile and progress improvements are included.

## Fixed

- No separate production bug fix is claimed in this patch. The new mist is suppressed on return, after a late model load and when opening an already active workstation, so it does not replay out of sequence.

## Install

1. Right-click the JARVIS tray icon → Quit.
2. Unzip JARVIS-1.81.3-update.zip into %LOCALAPPDATA%\Programs\JARVIS Armor Workspace\resources and choose Replace.
3. Start JARVIS.

This local preview update works over v1.80.1 through v1.81.2. It includes the approved halls and the Batmobile; keep your existing suit models and videos. The source ZIP is a development backup, not the installation file. Binary media is excluded from the source backup as requested.

## Undo

Use the tray → RESTART WITHOUT SELF-UPDATES, or reinstall the v1.80.1 zip. The tray command bypasses self-updates; reinstall the v1.81.2 update ZIP to undo this base preview.
