## JARVIS 1.83.0: Work desk and everyday routines

## What's new

- Work desk turns your bullet points into editable branded proposals and quotes, with exact supplied prices and missing details marked for review.
- Ask your files searches a chosen Documents folder and gives answers with checked excerpts, filenames and page, paragraph or line references.
- JARVIS, Alfred and Karen use distinct conversational tones in their halls, with a switch to turn personalities off.
- Retire accepted Tower projects to a dated trophy wall with their actual suit portraits and saved results, and export a local portfolio page.
- Photo drop saves WhatsApp photos locally; optional paid reading files receipts as expenses, business cards as contact files and evidenced whiteboard actions as to-dos.

- Meeting mode prepares decisions, named action owners and stated deadlines, adds supported actions to your to-dos, and saves an editable follow-up for your approval.
- When a recorded Teams or Zoom call shows a recognised ended-call screen, JARVIS can finish the notes automatically; the End button remains available.
- Travel mode lets you review a destination and full dates, moves wake-up calls to destination local time during your stay, then returns recurring calls to the computer's time zone.
- Selected flight numbers can be watched in new inbox emails for gate, terminal, delay and cancellation notices; destination weather and a seven-day forecast are available.
- Hulkbuster's eyes turn red for a newly classified angry customer email; Mark 1 glows after a successful approved-update export or a successful build reported by a configured agent.
- The Needs my attention shelf brings together blocked work, approvals, finished work awaiting review, meeting drafts and saved page briefs across the three halls.
- Drag a JARVIS tab onto a suit, or use the page-sharing controls, to prepare a summary, research, comparison or task brief for that suit's team.
- Preview half-screen and quarter-screen layouts when moving floating JARVIS windows, and choose layouts when moving tabs to another screen.
- WhatsApp Ogg voice notes can use OpenAI transcription, with a daily spending cap and a clear repeat-back; audio cannot approve or decline requests.
- A Sunday 18:00 review covers accepted results, rework, open to-dos, recorded spend, email actions and the week ahead.
- A nightly 02:00 OneDrive backup saves settings, suit configuration, notes, standing orders and local work history; a missed backup catches up when JARVIS next opens.
- Approved self-updates can export a local update ZIP, a code backup and release notes, with a distinct version and verified contents.
- Core's new Routines tab and the feature guide explain where to find these features; all earlier halls, mist, sounds, poses and holograms are retained.

## Fixed

- The document reader uses the compatible PDF.js build, after real PDF extraction tests caught a missing runtime method.
- Source links refuse changed documents, and answers without verifiable supporting quotes fall back to the original passages.
- Duplicate photos do not trigger repeat charges or duplicate whiteboard tasks; failed photo readings keep their reserved allowance and never retry automatically.
- A failed PDF export retains the current editable HTML proposal and cannot open an older PDF by mistake.

- Meeting follow-ups no longer send automatically when recording ends; each exact edited email needs approval.
- A restarted meeting draft does not duplicate its to-dos, and an interrupted email send is not silently repeated.
- Travel approvals refuse to apply stale one-off alarm changes, and wake-up confirmations use the destination time zone during travel.
- Normal spoken wake-up confirmations retain their familiar wording; two core checks caught formatting regressions, which were fixed in code without changing the tests.
- Tab capture rejects closed or changed pages and excludes form inputs; page text stays untrusted when passed to agents.
- Saved page briefs cannot start twice or silently expand their budget through a floor handoff.
- The attention shelf opens the correct hall and result instead of relying on whichever hall is currently visible.
- Cancelling a window or tab grab releases its preview, and edge snapping honours screen coordinates and available work areas.
- Brief Windows file locks are retried when saving Tower work and to-dos.
- Unreadable saved page briefs and meeting drafts are preserved instead of being overwritten.

## Install

1. Right-click the JARVIS tray icon → Quit.
2. Unzip JARVIS-1.83.0-update.zip into %LOCALAPPDATA%\Programs\JARVIS Armor Workspace\resources and choose Replace.
3. Start JARVIS.

Keep existing suit models and other installed media. app.asar must be directly inside resources. This cumulative ZIP contains changed media since v1.80.1 and the Windows helper for meeting-end detection. The source ZIP is a development backup, not the installed update.

The last verified installed base before this release is 1.82.3. Creating these ZIPs does not install them. The new base version sets aside older self-updates; inaccessible old self-update files have not been merged. Installation, when completed, is recorded in a separate receipt.

Open Core → Work desk for proposals, file answers, trophies, photo filing and branding. Add your business name and optional logo before drafting. Paid Claude photo reading is OFF by default; enable it explicitly in Photo drop if wanted. Its default daily cap is US$1, with US$0.05 reserved per reading. Files are searched locally; matching excerpts go to the configured Claude API for an answer. Scanned PDFs need an OCR text copy. Review extracted prices, dates, contacts and actions before using them. Exported proposals remain drafts and are never sent automatically. PDF export needs a working Electron renderer; if it fails, the current editable HTML document is kept. Existing installed system voices remain in use; personalities change conversational tone, not actor voices. Retiring a project preserves its result while keeping the working suit available.

Open Core → Routines for meeting drafts, travel, report previews, backups and local release exports. Start Meeting mode before recording a call and select microphone plus call audio. Automatic ending requires JARVIS to observe an active call and then a stable explicit ended-call screen; silence, closing a window or an unreadable screen do not count. It supports the desktop Teams/Zoom interfaces and supported call pages inside JARVIS. Other browsers or unrecognised interfaces need the End button. Offline Windows speech recognition and a configured summary engine are required. Check the extracted actions and dates.

Travel needs full arrival and last-day dates, a searched destination and approval. Only wake-up calls move; existing unrelated reminders and appointments keep their times. Email alerts require a connected inbox and selected flight numbers, and are not live airport data. JARVIS must be running with the computer awake for calls, recording, checks and schedules.

The requested routine defaults are Sunday 18:00 and nightly 02:00 in the saved local time zone. OneDrive must be configured on the PC; its own client controls cloud syncing. Backups exclude passwords, browser sign-ins, recordings, large models and original work documents, Work desk exports, saved trophy results and Photo inbox files. The backup includes their indexes; back up Documents/JARVIS/Work desk and Photo inbox separately. Reconnect accounts after restoring.

Voice notes require working Twilio WhatsApp access, an OpenAI API key and enabling Voice notes in Core Settings. Each accepted note reserves US$0.03 from the daily cap before transcription; ambiguous failures retain the allowance. Notes are limited to five minutes and 4 MB. Audio is not saved by this transcription feature. Twilio charges are separate. The earlier Meta restriction review has not been confirmed resolved.

Configured agents can print BUILD PASS after a successful build; Mark 1 reacts only when that process also exits successfully. BUILD FAIL, cancellation and non-zero exits do not trigger it. This does not watch unrelated external build systems. Suit reactions expire and respect reduced motion.

Self-update exports verify the approved manifest and package contents. They save locally and do not run the full developer test suite or publish to GitHub. Their source ZIP is a code backup of the installed app, not a full repository export. Test them before sharing.

## Undo

Restore the resources backup made before installation, or reinstall the previous update ZIP. Tray → RESTART WITHOUT SELF-UPDATES bypasses later self-updates; it does not undo a replaced base release. Reinstalling the v1.80.1 ZIP is an older fallback.
