## JARVIS 1.107.0: Floorboard can follow the Tower

## New

- **Floorboard's JARVIS card can see and start Tower work.** While JARVIS runs, other apps on this PC can now:
  - see what each floor is doing and how far it has got, and what finished in the last two days;
  - see the same "needs you" list as the work shelf;
  - hear when a job finishes or stops, when the morning brief is ready, and when something new needs you;
  - start a marketing job from artwork you drop in. You choose the suit and the client. JARVIS shows a summary first (which floor, where the files go, the most it can spend), and starts only when you confirm.
- **Where dropped artwork goes.** It goes into the client's folder, in a dated `Artwork 2026-11-06` folder inside the numbered folder that fits the job: `03 Social posts` for posts, `05 Campaigns` for a campaign, and `01 Brief and brand` otherwise. A copy goes into the floor's knowledge, so its agents can open the pictures. Nothing that is already there is replaced.
- **The same limits as the Start button.** Every job stays inside the floor's spend caps per run and per day. Nothing is sent or posted: drafts still wait for your OK in JARVIS.

## Safe by design

- Only apps on this PC can reach it, and only with a key that JARVIS writes to a file only your account can read. It is a new key each time JARVIS starts, and the file is removed when JARVIS quits.
- That key opens the Tower, the "needs you" list and the suit list. It cannot open the control deck's bays or change their agent commands.

## Install

Click **Install now** on the banner in JARVIS, or **INSTALL JARVIS 1.107.0** in the tray menu. On the Mac mini, click **Install now** as well.

Or, on Windows, by hand:

1. Download `JARVIS-Armor-Workspace-1.107.0-update.zip` below, right-click it and choose **Extract All…**.
2. Open the extracted folder and double-click **INSTALL-UPDATE.bat**. It closes JARVIS, keeps a copy of the old version, copies the update in and starts JARVIS again.

Your previous version is kept in `resources\backup-before-1_107_0`.
