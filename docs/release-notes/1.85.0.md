## JARVIS 1.85.0: automatic task skills

## What's new

- Finished Tower tasks now save their methods, checks and preferences as reusable skills automatically.
- Relevant skills help the next task on the same floor, including work started from meeting follow-through.
- Open Tower → a floor → Skills to inspect recipes, search older work and switch skills off.
- Choose whether skills start helping after you accept the result (the default) or after the agent review passes.
- Skills stay saved when old tasks leave History and are included in your settings backup.
- See how often each skill was used and how many later results you accepted or returned for rework.
- Eligible tasks already in the retained History are captured once when this version starts.

## Fixed

- Useful task methods no longer depend on remembering to save a workflow manually.
- Rejected work and failed reviews cannot become active skills; rehearsals are excluded.
- Repeated saving and restarts do not duplicate skills, and unrelated floors cannot use each other's recipes.
- A skill-saving error leaves the completed deliverable available and displays a retry message.

## Install

1. Right-click the JARVIS tray icon → Quit.
2. Unzip JARVIS-1.85.0-update.zip into %LOCALAPPDATA%\Programs\JARVIS Armor Workspace\resources and choose Replace.
3. Start JARVIS.

The source zip is a backup for development, not the desktop update. This package has not been installed on your PC by Codex. Installing a new version sets aside self-updates built on an older version.

## Undo

For a self-update, use tray → RESTART WITHOUT SELF-UPDATES. To undo this installed release, quit JARVIS and reinstall the v1.84.0 update zip. Keep a copy of your settings before reverting.
