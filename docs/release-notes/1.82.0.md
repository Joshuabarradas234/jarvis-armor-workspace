## JARVIS 1.82.0: Useful work and clearer controls

Review build: automated checks and packaging passed; visual and physical input checks remain incomplete. This has not been installed on your desktop or published as a stable release.

## What's new

- Tower briefs capture the outcome, audience, source files, constraints, budget, writing preferences, checklist and what finished means.
- Missing critical information pauses work with specific questions; default briefs can be saved for recurring and scheduled tasks.
- Failed reviews return to the workers for one correction pass; unresolved work stays blocked and never goes to the next floor.
- Accept a reviewed result, then save its brief and example as a reusable workflow in Results & workflows.
- Results & workflows shows accepted work, rework, completion time and estimated cost per accepted result, with a comparison across floors.
- Think can suggest improvements from local suit opens, repeated tab moves and Tower outcomes, with an on/off button and a maximum of two suggestions per day.
- Suggestions do not read other apps, web-page text or screenshots, spend credits, or make changes; ask for a plan and approve work through the existing process.
- The ? button opens a searchable guide to JARVIS features, including what each feature needs and where to find it.
- Right-click a suit tab, or press Alt+Shift+M, to move its live page to a chosen screen or return it to the suit.
- With Hands enabled, hold a pinch on a tab title, move towards another screen, check the destination preview and release; Escape or lost tracking cancels the move.
- Opening a suit case now emits cold mist from the lower seals; it clears in about 1.2 seconds and follows graphics quality and reduced-motion settings.
- The hall calibration shortcut has been removed from the toolbar; advanced calibration remains in the feature guide.
- Includes the earlier approved halls, suit effects, rotating Batmobile hologram and live suit progress improvements.

## Fixed

- A CHANGES review or missing verdict can no longer silently become Done or trigger a handoff.
- Older history entries marked Done despite a CHANGES verdict are reopened as needing correction.
- Invalid work plans and missing dependencies stop before a worker receives unfinished inputs.
- Unaccepted reviewer output is no longer automatically taught to the floor as a successful example.
- Repeated acceptance clicks no longer award extra experience; rehearsals cannot become accepted workflows or trigger real handoffs.
- Runs started in the same minute get separate work folders, preserving their drafts and review records.
- A disconnected target display no longer silently moves the tab onto the primary screen.
- A pinch inside a web page no longer triggers the old downward tab throw.

## Install

1. Right-click the JARVIS tray icon → Quit.
2. Unzip JARVIS-1.82.0-update.zip into %LOCALAPPDATA%\Programs\JARVIS Armor Workspace\resources and choose Replace.
3. Start JARVIS.

This is a cumulative drop-in update over v1.80.1 through v1.81.2. Keep your existing suit models and other installed media. The source ZIP is a development backup, not the installation file.

For the mist, turn animations on and disable reduced motion. Low/battery quality uses two wisps, medium four, and high/ultra six. It appears only during a fresh suit opening, not on return or an already-open workstation.

Screen numbers follow left-to-right, then top-to-bottom order and may differ from Windows display numbers. This moves JARVIS tabs; it does not take over tabs in another browser. The existing Control Deck remains available.

## Undo

Use the tray → RESTART WITHOUT SELF-UPDATES, or reinstall the v1.80.1 zip. The tray command bypasses self-updates only; to undo this base update, reinstall the v1.81.2 update ZIP. User data is not deleted by either ZIP.
